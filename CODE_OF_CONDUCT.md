# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) without modification.

The full text — including expected behavior, unacceptable behavior, enforcement responsibilities, scope, and the enforcement guidelines — is published at the link above. Read it before participating.

## Reporting

To report behavior that violates the Code of Conduct, email **conduct@re-entry.ai**. Reports are confidential. We will respond within five business days.

Maintainers who are themselves the subject of a report will recuse from handling it.
